# Would That I — Interactive 2D Forest, Foggy Window & Guitar Visualizer

An interactive 2D woodland rain & music experience inspired by Hozier's *"Would That I"*.

## Features
- **Custom 2D Hand-Drawn Artwork (`oak_canopy_2d.jpg` & `forest_bg.jpg`)**: Transformed from a real photograph of gnarled oak branches with sunlight filtering through the forest canopy.
- **Tactile Foggy Windowpane**: Condensation builds on the glass while raindrops trickle down and carve clear paths. Move your mouse across the screen to wipe the fog off the window by hand.
- **Playable 6-String Acoustic Guitar**: Strum the 6 strings on screen with your mouse, or play using keyboard keys `A S D F G H` (individual strings), `Space` (full chord strum), and `1–4` to switch between *"Would That I"* chord voicings (`G`, `Em7`, `Cadd9`, `D`).
- **Procedural Rain & Woodland Audio Engine**: Zero external audio samples required—synthesizes stereo canopy rain, leaf droplet patter, and hearth crackles in real time using the Web Audio API.
- **Real-Time 4-Stem Instrument Dissector**: Drag and drop any `.mp3` / `.wav` audio file onto the window to dissect **Fingerpicked Guitar**, **Vocals & Choir**, **Kick Stomp & Bass**, and **Claps & Shakers**, driving sunbeams, embers, and rain shimmer in real time.

## How to Run
Open `would_that_i_forest.html` (or `index.html`) in any modern web browser.
